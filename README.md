# Kaspi Waybill Summary

Статический браузерный dashboard для ежедневной сводки по PDF-накладным из ZIP-архива. Интерфейс построен на основе `Theme1` из исходного dashboard template.

## Что работает в MVP

- drag-and-drop и выбор ZIP;
- пакетное чтение PDF через JSZip и PDF.js;
- прогресс, остановка и продолжение обработки;
- извлечение номера заказа, товара, количества, города, службы/ПВЗ, адреса, даты доставки и веса;
- сводка по товарам, городам и нишам;
- поиск, сортировка, inline-переименование и сохранение правил;
- компактная история дней в `localStorage`;
- экспорт и импорт истории JSON.

OCR не используется. Сканированные PDF без текстового слоя будут отмечены как ошибки.

## Локальный запуск

Самый надежный способ:

```powershell
python -m http.server 8080
```

Затем открыть `http://localhost:8080/`. Также можно открыть `Theme1/index.html` напрямую, но некоторые браузеры ограничивают worker PDF.js для `file://`.

## Загрузка ZIP

1. Откройте раздел «Загрузка ZIP».
2. Выберите дату сводки.
3. Перетащите ZIP или нажмите «Выбрать ZIP».
4. Дождитесь обработки или остановите ее кнопкой.
5. После остановки можно продолжить текущую сессию или выбрать архив заново.

Все PDF обрабатываются локально в браузере. Архивы и полные тексты PDF не сохраняются.

## Данные браузера

В `localStorage` сохраняются:

- компактные результаты обработанных дней;
- правила переименования товаров;
- ручные правила ниш;
- настройки рабочих дней.

Историю можно экспортировать и импортировать JSON в разделе «История».

## Netlify

- Build command: оставить пустым.
- Publish directory: `.` (корень репозитория).

Файл `netlify.toml` уже содержит publish directory. Корневой `index.html` перенаправляет на приложение в `Theme1`.


## Основа и лицензии

Проект сохраняет структуру fork от `fazeelkhalid/Free-Responsive-Web-UI-Kit---Dashboard-Template-bootstrap`. JSZip и PDF.js загружаются с публичного CDN и используются только в браузере.
